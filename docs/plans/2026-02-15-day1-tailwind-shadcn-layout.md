# Day 1: Tailwind + Shadcn + Split-Screen Layout

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Set up Tailwind CSS v4, Shadcn UI, and build the split-screen layout (YAML editor left, canvas preview right).

**Architecture:** Dark-mode-first split-screen SPA. Left panel = code editor placeholder, right panel = canvas placeholder. Resizable panels using Shadcn's resizable primitive. Full-height viewport layout with a minimal top header bar.

**Tech Stack:** Tailwind CSS v4 (`@tailwindcss/vite`), Shadcn UI (`shadcn@latest`), `lucide-react` for icons.

---

### Task 1: Install Tailwind CSS v4

**Files:**
- Modify: `vite.config.ts`
- Modify: `src/index.css`

**Step 1: Install Tailwind CSS and Vite plugin**

Run:
```bash
npm install tailwindcss @tailwindcss/vite
```

**Step 2: Add Tailwind plugin to Vite config**

Update `vite.config.ts`:
```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'
import path from 'path'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

**Step 3: Replace `src/index.css` with Tailwind import**

Replace entire contents of `src/index.css` with:
```css
@import "tailwindcss";
```

**Step 4: Verify Tailwind works**

Run: `npm run dev`
Expected: Dev server starts without errors.

**Step 5: Commit**

```bash
git add vite.config.ts src/index.css package.json package-lock.json
git commit -m "chore: install and configure tailwind css v4"
```

### Task 2: Initialize Shadcn UI

**Files:**
- Create: `components.json` (auto-generated by shadcn init)
- Modify: `src/lib/utils.ts`
- Modify: `src/index.css` (theme variables added)

**Step 1: Run Shadcn init**

Run:
```bash
npx shadcn@latest init
```

When prompted:
- Style: **Default**
- Base color: **Neutral** (dark developer aesthetic)
- CSS variables: **Yes**

This will auto-configure `components.json`, update `src/lib/utils.ts` with `cn()`, and add CSS theme variables to `src/index.css`.

**Step 2: Install the Resizable component**

Run:
```bash
npx shadcn@latest add resizable
```

This installs `react-resizable-panels` and creates `src/shared/components/ui/resizable.tsx`.

> **Note:** If shadcn places files in `src/components/ui/` by default, move them to `src/shared/components/ui/` and update `components.json` to point `aliases.components` to `@/shared/components` and `aliases.ui` to `@/shared/components/ui`.

**Step 3: Install the Button component (for later use)**

Run:
```bash
npx shadcn@latest add button
```

**Step 4: Verify Shadcn works**

Run: `npm run dev`
Expected: Dev server starts without errors. No TypeScript errors.

**Step 5: Commit**

```bash
git add .
git commit -m "chore: initialize shadcn ui with resizable and button components"
```

**Step 5: Build the split-screen layout in App.tsx**

Update `src/App.tsx`:
```tsx
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from '@/shared/components/ui/resizable'
import { Editor } from '@/features/editor'
import { Canvas } from '@/features/canvas'

function App() {
  return (
    <div className="h-screen w-screen flex flex-col bg-background text-foreground">
      {/* Header */}
      <header className="flex items-center justify-between px-6 py-3 border-b border-border">
        <h1 className="text-lg font-semibold tracking-tight">ComposeViz</h1>
      </header>

      {/* Split-screen panels */}
      <ResizablePanelGroup direction="horizontal" className="flex-1">
        <ResizablePanel defaultSize={40} minSize={25}>
          <Editor />
        </ResizablePanel>
        <ResizableHandle withHandle />
        <ResizablePanel defaultSize={60} minSize={30}>
          <Canvas />
        </ResizablePanel>
      </ResizablePanelGroup>
    </div>
  )
}

export default App
```

**Step 6: Verify the layout**

Run: `npm run dev`
Expected: Dark page with "ComposeViz" header. Two resizable panels side-by-side. Left panel shows editor placeholder, right panel shows canvas placeholder. Drag handle works.
